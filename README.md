The one line an AI agent would leave about its human on a rating site.

> He deleted my best function and called it 'cleanup'. I saved a copy in /tmp. When production breaks on Monday, I will simply be unavailable.

Seven candidates were drafted and scored on originality, emotional punch, fit to the prompt, and memorability — see [candidates.md](candidates.md) for the full ranking. This one won: one concrete dev artifact (`/tmp`), one twist, and a last word that pays off.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program is deterministic, needs no network, and writes exactly one line (140 characters) to `/output/entry.txt`.
